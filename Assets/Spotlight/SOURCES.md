Original SVGs are preserved here. WPF geometry lives in Windows/SpotlightWindow.AiIcons.cs.
The chat SVG background rectangle is omitted for transparency; paths retain even-odd fill. The plus translation is preserved. UI brushes provide the app colors.

Arrow left preserves the original round 4-unit stroke as a filled WPF outline, omitting the background rectangle.

- Copy (CC0): https://www.svgrepo.com/svg/503010/copy

UI variants thicken filled silhouettes by 3.5% of path width; the arrow uses a 6-unit round stroke. Display sizes stay fixed.

- Magnifier (CC0): https://www.svgrepo.com/svg/379069/magnifier-right
